# blue-team



This repository generates a README file that outlines the initial steps for analyzing unpreprocessed data across different imaging modalities (EEG and fMRI). 
Please, drop your input file (EEG formats: .edf, .tsv, .json; or fMRI formats:.nii/.nii.gz) in ....

The generated README file provides:
- The modality of the data used (EEG or fMRI)
- Detailed information regarding sequences and adquisition times, among others
- Guidance on subsequent preprocessing steps
- Quality control metrics
- Relevant warnings/recommendations
- Visualization plots and their interpretation
